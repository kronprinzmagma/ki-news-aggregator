# Build-Anker

Baue mit der OpenAI Assistants API einen Mini-Agenten, der eine Textaufgabe (z.B. Zusammenfassung + einfache Tabelle) in einem einzigen Prompt-Ablauf löst, und miss, bei welchem Schritt der Agent abbricht oder nachfragt – so siehst du konkret, wo agentic Handoff heute noch bricht.

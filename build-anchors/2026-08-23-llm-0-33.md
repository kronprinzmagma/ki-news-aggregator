# Build-Anker

Installiere `llm 0.33` via `pip install llm`, erstelle zwei Vorlagen – eine mit Modellkonfiguration, eine mit Prompt – und kombiniere sie mit `-t vorlage1 -t vorlage2`; miss, ob die kombinierte Ausgabe konsistenter ist als eine einzelne Vorlage.

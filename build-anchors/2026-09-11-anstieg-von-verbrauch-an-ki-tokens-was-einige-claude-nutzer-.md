# Build-Anker

Ruf über die Anthropic-API stündlich deinen Token-Verbrauch ab und logge ihn in eine einfache CSV-Datei – sobald der Anstieg zwischen zwei Abfragen einen selbst gesetzten Schwellenwert überschreitet, schickst du dir eine E-Mail-Warnung; so siehst du sofort, ob dein Konto ohne dein Zutun Tokens verbraucht.

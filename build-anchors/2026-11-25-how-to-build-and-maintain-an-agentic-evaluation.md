# Praktischer Hinweis

Formulieren Sie für ein eigenes Werkzeug **eine enge, prüfbare Behauptung** in einem Satz. Lassen Sie Ihren Agenten dieselbe Aufgabe dreimal laufen und vergleichen Sie die Ergebnisse. Schwanken sie stark, ist Ihr Test noch nicht verlässlich.
